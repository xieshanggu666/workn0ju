# 🏠 智居 · 智能家居场景联动与设备健康看板

基于 **Vue 3 + Vite + Pinia（前端）+ Express + SQLite（后端）** 的智能家居演示看板。纯 mock 设备数据，无真实硬件接入。

## 技术栈

- 前端：Vue 3 + Vite + Pinia
- 后端：Node.js 内置 `node:sqlite` + Express，REST API
- 数据库：`server/home.db`（SQLite，首次启动自动建表 + 预置演示数据）

## 运行

```bash
npm install
npm run dev
```

前端 http://localhost:5190（Vite 已代理 `/api` 到 http://localhost:4120）。
需 Node ≥ 22.13。

## 测试

```bash
node test/quota.e2e.mjs       # 调周期/调额度后的身份、留痕、状态流转、通知去重（42 项）
node test/quota.migrate.mjs   # 旧库身份键升级迁移，历史告警与原 id 保留（10 项）
```

## 功能

- **健康看板**：设备在线/异常统计、房间分布、设备类型、告警中心（低电量/信号弱/离线/能耗尖峰/定额超标）、全屋 24h 能耗趋势、定额执行情况
- **设备管理**：按房间/类型/状态筛选，添加/删除设备，开关切换，功率编辑、电量/信号条
- **场景联动**：可视化动作编排（设备→动作），创建/启用停用/触发场景，触发后写入日志并联动开关真实设备状态
- **能耗统计**：按设备开关/功率变化分段累计用电（功率×时长），近24小时总量、按房间分布、设备用电排行、实时功率、节能提示；已删除设备历史保留并标记；页面底部联动展示周期定额用量
- **能耗定额与超标预警闭环**：按房间/设备配置日、周（周一起）、月额度；持续聚合「已结分段 + 运行中设备实时折算」用量；80% 预警、100% 超标，同一身份只通知一次且可由预警升级为超标；**调整周期或额度后按最新配置即时对账**（旧周期告警结转留痕、阈值变化驱动升级/降级/解除/已闭环重开，快照同步看板与处理记录）；告警保留 待处理→处理中→已处理/已忽略 状态与处理备注；额度新建/调整/停用/删除全程留痕（含对象快照，删后不丢名）；跨周期自动结转、停用/删除额度自动解除、重新启用仍超限自动重开；看板告警与能耗统计联动，新告警/升级/重开 toast 通知，节拍幂等不重复打扰
- **日志时间线**：所有操作与预警/超标通知的实时记录

## 分段用电模型

- `energy_segments`：每台开启运行中设备的段首（设备标识 + 名称/房间/功率快照 + 起始时间）。开关切换、功率编辑、改名、换房时旧段立即结落，再按当前状态开新段
- `energy_records`：结落的分段明细，按 `device_id` 稳定归属（删除设备不级联），含完整 ISO 起止时间、产生时的名称/房间快照与 kWh；服务端每 30s 模拟运行节拍结段续开，明细保留 7 天
- 旧版 `energy(device_name,room,kwh,hour)` 数据首次启动自动迁移：名称唯一命中的绑定设备标识，重名/设备已删除的不猜绑，保留名称房间快照（排行中标记「旧记录」）
- 看板 24h 趋势、能耗排行与尖峰告警均读自分段记录；前端 20s 自动刷新

## 能耗定额与超标预警模型

- `energy_quotas`：定额配置（scope=room/device × period=daily/weekly/monthly + limit_kwh）。同一对象同一周期唯一；设备定额按 device_id 稳定归属，设备删除后额度保留并标记，历史告警不丢
- `quota_alerts`：告警实例，身份键 `UNIQUE(quota_id, period, period_start)`——周期类型是身份的一部分，调周期后旧告警原样留痕、同起点不同周期不撞键；80% 为 warn、100% 为 error；状态机 `open → handling → resolved / ignored`（可退回、可重开），处理备注、handled_at 与 notified_at（最近一次通知批次）保留。调额后评估器按最新配置对账：阈值放宽未闭环告警降级/解除，阈值收紧或停用后重新启用导致仍超限时同 id 重开（仅重开一次，用户主动闭环不被用量自然增长复活），limit/period/名称快照同步刷新
- `quota_adjustments`：额度新建/调整/启停/删除留痕（旧值→新值、周期变化、原因、scope/对象名快照），额度删除后仍可按额度与全局查看，支持按额度查看与全局查看
- 用量聚合：周期内 `energy_records` 已结分段之和 + `energy_segments` 未结段实时折算（当前功率×已运行时长，重启最长补 1h）；房间按产生用电时的房间快照归并，设备按稳定 device_id 归并
- 评估节拍：服务端每 30s 全量评估（幂等：无新事件不刷 notified_at、不发通知）；设备开关/更新/删除、额度增改/启停后立即评估；跨周期与换周期的旧告警按身份自动结转关闭（备注区分「周期结束」与「周期调整」），停用/删除额度自动解除未关闭告警，重新启用仍超限则重开；触发/升级/重开时写日志时间线作为通知，前端按 `id+notified_at` 批次去重弹 toast
- 统计联动：健康看板新增「定额执行」卡片且告警中心中的定额告警可点击直达处理；能耗统计页底部展示用量占比最高的定额进度；定额 Tab 角标显示待处理/处理中数量
